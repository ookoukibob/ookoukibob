# Maintaining this profile

This repository is the special GitHub profile repository for **@ookoukibob**. GitHub renders the root `README.md` on the account profile page.

## Files

- `README.md` — primary English profile.
- `README.zh-CN.md` — Simplified Chinese version, linked from the primary README.
- `assets/profile-banner.svg` — original header artwork.
- `assets/project-*.svg` — original project cover artwork.

The SVGs are original editorial illustrations, not screenshots of the applications. Keep them as local repository assets so they render without third-party image hosting.

## Updating locally

```bash
git clone https://github.com/ookoukibob/ookoukibob.git
cd ookoukibob
# edit README.md, README.zh-CN.md, or assets/
git add README.md README.zh-CN.md assets/
git commit -m "Update profile"
git push
```
