# ookoukibob

student. mostly here to make things and figure out how they work.

I write software for problems I run into or ideas I can't leave alone. Lately that's been a mix of pharmacology, music, and hardware.

- [Neuropharmacology Sandbox](https://github.com/ookoukibob/Neuropharmacology-Sandbox) — a local-first pharmacology calculator with explicit inputs and data sources.
- [Polyrhythmic Metronome](https://github.com/ookoukibob/polyrhythmic-metronome) — an offline metronome for arbitrary time signatures. 59/16 is not a typo.
- [TextDeck](https://github.com/ookoukibob/TextDeck) — a Windows text input tool using SendInput, virtual HID, or an ESP32-S3.

Also into bass, drums, wind instruments, riichi mahjong, and whatever else catches my attention.

I post more random stuff on [X](https://x.com/ookoukibob).
